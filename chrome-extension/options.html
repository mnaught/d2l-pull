Post-processor

A program to run after the download, such as a converter script. It runs in a console window so it can ask questions. Your computer's D2L Pull helper must approve it once.

Add-ons

Source add-ons bring in data from other platforms (e.g. CompTIA CertMaster). They're separate extensions; approve one here before D2L Pull uses it.

Helper

Post-processors need the small D2L Pull helper on this computer. Install it once by running native\install.cmd (Windows) or native/install.sh (Mac/Linux) from the D2L Pull folder, then restart the browser.

Backup and sharing

Export your settings to a file, to back them up or share a course setup with a colleague. Importing replaces your current settings.
